# A股回测约束细则与常见失真

## 一、引擎实现的规则

| 规则 | 实现位置 | 细节 |
|---|---|---|
| 信号滞后 | `engine.run_backtest` | 第 i 根收盘的信号在第 i+1 根开盘成交，没有"当天收盘成交"的选项 |
| T+1 | 同上 | 买入发生在第 i+1 根，卖出最早在第 i+2 根，结构上不可能当日回转 |
| 涨停 | 同上 | 成交价 ≥ `limit_up` 时买入失败；`limit_up = round(昨收 × (1+pct), 2)` |
| 跌停 | 同上 | 成交价 ≤ `limit_down` 时卖出失败，持仓顺延，等下一个开盘 |
| 停牌 | 同上 | `volume <= 0` 视为停牌，当日不成交 |
| 整手 | 同上 | 主板/创业板 100 股，科创板 200 股起；买入股数向下取整到整手 |
| 资金不足 | 同上 | 一手都买不起时计入 `blocked_cash`，不产生交易 |
| 费用 | `engine.fees_for` | 佣金 max(成交额×0.00025, 5) + 印花税卖出 0.0005 + 过户费双向 0.00001 |
| 期末平仓 | 同上 | 最后一根按收盘价强制平仓，并在 `Trade.forced` 标记 |

涨跌停幅度按板块：主板 10%、创业板/科创板 20%、北交所 30%、主板 ST 5%。

## 二、常见回测失真（这个引擎帮你挡掉的）

### 1. 收盘价成交
用当日收盘价买入，等于假设你能在收盘的同一瞬间看到收盘价并成交。真实情况是：收盘价出来时已经收市，你只能挂次日单。**这是回测收益虚高最常见的来源，尤其在动量策略上。**

### 2. 一字板照样买进
连板股第二天一字涨停，模型照样以涨停价成交。真实盘口是：涨停价上排着几十万手买单，你根本排不到。引擎会把这种买入记成 `blocked_buy`，报告里能看到次数。

### 3. 忽略整手
模型买 4370 股，实际只能买 4300 股。对高价股影响巨大——100 万资金买茅台，一手就 15 万，仓位精度只有 15%。

### 4. 费用漏算印花税
A 股卖出单边 0.05% 印花税，加上佣金和过户费，一次完整买卖约 0.1%。**周均交易 5 次以上的策略，一年费用能吃掉 25% 的本金**（对 10 万本金约 2.5 万）。

### 5. 停牌当正常交易
停牌期间价格不动，模型会以为"波动率为零、稳赚不赔"，复牌后一根跳空全部还回去。

### 6. 前复权带来的未来信息
前复权价格用**未来**的分红送转调整历史价格，回测里看到的"历史低点"其实是按今天股本折算的。做长期回测时更稳妥的是用不复权价 + 单独处理除权，或者只在短周期用前复权。

## 三、自查清单（拿到任何回测报告先问这五个）

1. **成交价是哪一根的？** 如果是信号当根的收盘价，收益立刻打七折看待
2. **有没有涨停买不到、跌停卖不掉的统计？** 没有的话，大概率没建模
3. **费用占初始资金多少？** 超过 2% 先降频
4. **持仓占比多少？** 低于 20% 说明大部分时间空仓，收益可能集中在一两段行情
5. **同期买入持有是多少？** 跑不赢基准的"策略"，不如直接躺平

## 四、这个引擎不做的

- 组合与仓位分配（多标的同时持仓、相关性、再平衡）
- 滑点冲击模型（只支持在开盘价上加固定比例）
- 融资融券（杠杆、利息、维保比例、强平）
- 分红再投资的精确处理
- 退市、ST 变更、停复牌的价格跳变
- 分钟级/Tick 级回测

要做这些，往上接 `position-sizing`、`portfolio-analytics`（把年化改成 252），或者直接上 vectorbt（但要自己补这套约束）。
